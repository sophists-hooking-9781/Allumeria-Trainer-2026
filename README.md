## 🎮 About the Game

Allumeria is an indie action-adventure RPG developed and published by Studio Zeldex. Released in 2024, it combines real-time exploration, resource management, character progression, and combat in a fantasy world shaped by light and darkness.

---

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Allumeria**. This trainer provides optional quality-of-life and progression controls for Allumeria. It can protect the player during exploration and combat, maintain key survival resources, and simplify progression while preserving the game's exploration, equipment, quest, and combat systems.

**Target Audience:** Players who want a more relaxed Allumeria experience, need help during difficult encounters, want to experiment with builds and abilities, or have already completed the game and are replaying it with reduced resource and progression constraints.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Infinite Health** — Prevents the player's health from decreasing during exploration and encounters.
- **Infinite Stamina** — Keeps stamina available for movement, evasion, and other stamina-dependent actions.
- **Infinite Mana** — Maintains the resource used for magical abilities and other mana-based actions.
- **No Equipment Durability Loss** — Stops supported equipment from losing durability during normal use.

### 🧰 Inventory

- **Unlimited Consumables** — Allows supported consumable items to be used without reducing their stored quantity.
- **Unlimited Currency** — Prevents the trainer-supported currency total from decreasing when purchasing items or upgrades.

### ⚔️ Combat

- **One-Hit Defeat** — Causes supported enemies to be defeated by a single successful attack.
- **Damage Multiplier** — Applies a configurable multiplier to the player's outgoing damage.
- **Defense Multiplier** — Reduces incoming damage by applying a configurable defensive multiplier.
- **Instant Ability Cooldowns** — Removes or shortens supported cooldown timers for abilities.

## 📖 Detailed Feature Guide

### Movement & Exploration

Load a save and enter active gameplay before enabling movement-related options. Infinite stamina keeps stamina available for repeated movement and evasive actions, but it does not move the character automatically or compatibility map boundaries. Disable the option before transitioning between areas if the game behaves unexpectedly.

### Tools & Inventory

Open the inventory or another active gameplay screen before changing item or currency values. Unlimited consumables applies to supported items when they are used, while unlimited currency protects the supported balance during purchases and upgrades. Confirm changes in the normal game interface and avoid rapidly buying or selling while an option is being enabled or disabled.

### World & Environment

The trainer does not unlock areas, complete quests, reveal undiscovered locations, or replace the game's progression systems. Explore normally, interact with the world, collect items, and save through the game's own save system. Disable trainer options before loading a different save to reduce the risk of carrying altered values between sessions.

### Combat & Weapons

Enter an encounter before enabling combat options. Infinite health protects the player, infinite mana supports repeated magical abilities, and instant cooldowns removes supported ability timers. One-hit defeat and damage multipliers affect supported enemies and attacks. Disable combat modifiers for scripted encounters, boss transitions, or cutscenes if an encounter does not advance normally.
